# Indeks laboratoriow

Dodawaj tutaj jeden katalog na kazde laboratorium. Po ukonczeniu zadania
uzupelnij tabele i ustaw status zgodnie z rzeczywistym stanem pracy.

| Nr | Katalog | Temat | Status |
|---:|---|---|---|

Aktualnie nie dodano jeszcze laboratorium. Skopiuj
`../templates/lab/README.md` jako punkt startowy pierwszego zadania.

## Statusy

- `DRAFT` - praca rozpoczęta albo nieukończona;
- `TO VERIFY` - kod lub wynik wymaga dodatkowego sprawdzenia;
- `VERIFIED` - rozwiązanie uruchomione i sprawdzone;
- `SUBMITTED` - wersja przekazana prowadzącemu.
